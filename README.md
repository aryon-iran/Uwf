# 🛡️ UWF Manager (نسخه امن)

یک ابزار حرفه‌ای و کاربردی به زبان PowerShell برای مدیریت **فیلتر نوشتن یکپارچه (Unified Write Filter - UWF)** روی ویندوزهای Enterprise، Education و IoT.

این پروژه توسط گروه برنامه‌نویسی **Aryon** طراحی شده است تا مدیریت کامپیوترهای مدارس و سازمان‌ها را بدون خطر خرابکاری، ساده و امن کند.

---

## ✨ امکانات و ویژگی‌ها

- ✅ **تشخیص خودکار:** بررسی می‌کند که آیا نسخه ویندوز شما از UWF پشتیبانی می‌کند یا خیر.
- ✅ **نصب آسان:** نصب قابلیت UWF فقط با یک کلیک (بدون نیاز به گشتن در Windows Features).
- ✅ **فعال‌سازی امن:** فعال‌سازی فیلتر و محافظت از درایو C با تأیید دو مرحله‌ای (برای جلوگیری از اشتباه).
- ✅ **غیرفعال‌سازی مطمئن:** خاموش کردن فیلتر برای مواقعی که نیاز به آپدیت یا نصب نرم‌افزار دارید.
- ✅ **گزارش وضعیت:** نمایش لحظه‌ای وضعیت فیلتر (روشن/خاموش) در بالای منو.
- ✅ **ری‌استارت هوشمند:** تایمر ۱۵ ثانیه‌ای برای ری‌استارت، با قابلیت لغو کردن.
- ✅ **ایمنی بالا:** برای کارهای خطرناک، از کاربر می‌خواهد کلمه `ENABLE` یا `DISABLE` را تایپ کند.

---

## 📖 درباره پروژه

**UWF Manager** یک اسکریپت PowerShell حرفه‌ای، امن و کاربرپسند است که برای مدیریت قابلیت **Unified Write Filter (UWF)** در ویندوزهای Enterprise، Education و IoT طراحی شده است.

این ابزار با هدف **ساده‌سازی مدیریت کامپیوترهای مدارس، کافی‌نت‌ها و سازمان‌ها** ساخته شده تا بدون نیاز به دانش عمیق فنی، سیستم‌ها در برابر تغییرات ناخواسته محافظت شوند و همیشه به حالت اولیه بازگردند.

> 💡 **UWF چیست؟** فیلتر نوشتن یکپارچه (UWF) یک قابلیت امنیتی در ویندوز است که به سیستم اجازه نمی‌دهد تغییرات روی درایو اصلی ذخیره شوند. با هر ری‌استارت، سیستم به حالت اولیه و تمیز بازمی‌گردد. این قابلیت برای محیط‌های عمومی (مثل مدارس) حیاتی است.
